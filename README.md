# GN Light — single file

The fast, lightweight GN Light game site in **one file**: **`index.html`** (about 6 MB).

The game list and every cover thumbnail are packed inside, so the site opens and browses with **no network at all**. Games load from the internet when you play them.

- **Open it anywhere:** double-click it on a computer, open it from a phone's Files app, or host it on any static host (Netlify Drop, GitHub Pages, Cloudflare Pages, Neocities).
- **Nothing to set up:** no accounts, no Firebase, no tracking. It sends nothing to any database, so it can't use anyone's Firebase usage.
- **Saves on your device:** favorites and recents are kept in your browser. Some phone file viewers don't allow saving; the game count then says "not saving". Open the file in Chrome or another browser to keep them.

## Keys

- **/**: search
- **Esc**: close the game
- **`** (backtick): leave fast

## What's different from GN Light

- Game list and thumbnails are inside the file (GN Light downloads them).
- No online counter, no service worker, no link back to the full site.
- Works when opened from a phone's Files app, where storage is blocked.
- Unity games no longer stop at the end of loading when the file is opened from disk.

## How it's made

Don't edit `index.html` by hand. It's generated by `build.py` from GN Light:

```
git clone https://github.com/SCHSwork/gn-light
pip install pillow
python3 build.py gn-light index.html
```

A GitHub Action (`.github/workflows/build.yml`) rebuilds it every day after GN Light updates its game list, and commits the new `index.html` when anything changed. You can also run it from the **Actions** tab → **Build single file** → **Run workflow**.
